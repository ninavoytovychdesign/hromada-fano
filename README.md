# Громада українців міста Фано

Сайт громади «Громада українців міста Фано» / Comunità ucraina di Fano. Гасло – «З Україною у серці».

Сайт складається з одного файлу `index.html`. Усередині три сторінки, між ними перемикає адреса після `#`:

- `#home` – Головна
- `#dovidnyk` – Довідник Фано. Розділи відкриваються за прямими адресами: `#dovidnyk-dokumenty`, `#dovidnyk-medytsyna`, `#dovidnyk-shkola`, `#dovidnyk-kursy`, `#dovidnyk-terminovo`
- `#fotoarkhiv` – Фотоархів. У кожного альбому своя адреса: `#fotoarkhiv/<id>`, наприклад `#fotoarkhiv/storia-di-una-foglia`

Альбоми, перегляд фото й форма «Написати нам» відкриваються поверх сторінки.

## Як подивитися сайт

Завантажте репозиторій кнопкою **Code → Download ZIP**, розпакуйте архів і відкрийте `index.html` у браузері.

## Що лежить у репозиторії

- `index.html` – увесь сайт: розмітка, стилі й скрипти
- `img/` – фото, орнаменти вишивки, лого й обкладинка для поширення `og-cover.jpg`
- `img/s/` – зменшені копії фото, 480 px завширшки, для мобільних і мініатюр
- `logo/` – лого громади у SVG: серце, горизонтальна й повна версія
- `docs/photo-consent.md` – фото з дітьми та де вони використані

## Контакти – в одному місці

На початку скрипту в `index.html` є блок `SITE`:

```js
const SITE = {
  email: "",
  facebook: "",
  formEndpoint: "",
  privacyUrl: ""
};
```

Вписуйте сюди лише підтверджені дані. Що з цього порожнє, того на сайті не видно:

- **`email`** – пошта громади. Без неї посилання на пошту немає ні у футері, ні у формі.
- **`facebook`** – сторінка громади у Facebook. Без неї немає жодної кнопки Facebook.
- **`formEndpoint`** – адреса сервісу форм. Без неї замість форми показується повідомлення «Форма запрацює найближчим часом» і перевірений канал зв'язку, якщо він є.
- **`privacyUrl`** – політика приватності. Без неї немає ні посилання у формі, ні у футері.

## Як підключити форму до пошти

1. Зареєструйтеся у [Formspree](https://formspree.io) на пошту громади.
2. Створіть форму й скопіюйте її адресу – вона виглядає як `https://formspree.io/f/abcdwxyz`.
3. Вставте адресу в `formEndpoint`.
4. Надішліть із сайту тестове повідомлення. Доставку можна вважати перевіреною, коли лист прийде на пошту. Formspree першого разу ще попросить підтвердити адресу.

## Публікація на GitHub Pages

Сайт лежить у корені гілки `main`, файл `index.html`. Файл `.nojekyll` вимикає обробку Jekyll.

Обліковий запис `ninavoytovychdesign` має власний домен `ninavoytovych.com`. Тому сайт відкриватиметься за адресою **https://ninavoytovych.com/hromada-fano/**, а адреса `ninavoytovychdesign.github.io/hromada-fano/` перенаправляє туди. Якщо там 404, перевірте в **Settings → Pages**:

1. **Source** – «Deploy from a branch».
2. **Branch** – `main`, папка `/ (root)`, потім **Save**.
3. Угорі має з'явитися «Your site is live at https://ninavoytovych.com/hromada-fano/».
4. Вкладка **Actions** – останній запуск «pages build and deployment» має бути зеленим.
5. **Enforce HTTPS** – увімкнено.

## Що ще потрібно від громади

- Пошта громади, адреса сторінки у Facebook і політика приватності.
- Обкладинка й фото альбому «Pagine del diario ucraino». Поки їх немає, альбом прихований.
- Згода батьків на фото з дітьми – див. `docs/photo-consent.md`.
- Роки на шести подяках, якщо вони відомі.
- Чисті скани подяк замість фото в рамках.
