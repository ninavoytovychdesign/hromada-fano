# Громада українців міста Фано

Сайт громади «Громада українців міста Фано» / Comunità ucraina di Fano. Гасло – «З Україною у серці».

Сайт складається з одного файлу `index.html`. Усередині три сторінки, між ними перемикає адреса після `#`:

- `#home` – Головна
- `#dovidnyk` – Довідник Фано
- `#fotoarkhiv` – Фотоархів

Альбоми, перегляд фото й форма «Написати нам» відкриваються поверх сторінки.

## Як подивитися сайт

Завантажте репозиторій кнопкою **Code → Download ZIP**, розпакуйте архів і відкрийте `index.html` у браузері.

## Що лежить у репозиторії

- `index.html` – увесь сайт: розмітка, стилі й скрипти
- `img/` – фото, орнаменти вишивки та лого для сайту
- `logo/` – лого громади у SVG: серце, горизонтальна й повна версія

## Що ще треба замінити перед запуском

| Що | Де в `index.html` |
| --- | --- |
| Пошта громади | рядок `const EMAIL = "[email громади]";` |
| Адреса сервісу для форми | рядок `const FORM_ENDPOINT = "";` – див. нижче |
| Посилання на Facebook громади | рядок `const FACEBOOK_URL = "";` – поки порожньо, кнопки Facebook сховані |
| Роки на 6 подяках | масив `THANKS`, там, де немає « · 2023» |
| Дати кількох альбомів | масив `ALBUMS`, значення `[дата]` |
| Обкладинка альбому «Pagine del diario ucraino» | масив `ALBUMS` |

## Як підключити форму до пошти Тетяни

Поки `FORM_ENDPOINT` порожній, форма нічого не відправляє і показує, що її ще не підключено. «Повідомлення надіслано» з'являється лише після успішного відправлення.

Щоб листи приходили на пошту:

1. Зареєструйтеся у [Formspree](https://formspree.io) на пошту Тетяни.
2. Створіть форму й скопіюйте її адресу – вона виглядає як `https://formspree.io/f/abcdwxyz`.
3. Вставте адресу в `const FORM_ENDPOINT = "...";`.

## Перед публікацією

На частині фото є діти. Поки немає згоди батьків, репозиторій лишається приватним, а сайт не публікуємо.
